intelligence vs cost

How to read this chart

Each point is one model variant, usually one reasoning effort level. A line joins the variants of one model family. Point at a variant, or tab to it, to see its details. Click it to pin it, then point at another variant to compare the two.

The X axis shows the cost to run one task of the Artificial Analysis Intelligence Index test suite. On the log scale, each grid step to the right multiplies the cost by the same factor. The Y axis shows the benchmark picked in the header. A higher score is better on all of them.

The dashed line is the Pareto line. A variant is on it when no other visible variant scores higher for the same or a lower cost. These variants give the best value for money. Zoom Y to Pareto fits the score axis to them.

Benchmarks

  • Intelligence is the Artificial Analysis Intelligence Index, a mix of many benchmarks.
  • Coding (SciCode) is the SciCode benchmark score, scaled from 0 to 100. This page uses SciCode because the models feed no longer supplies the former Coding Index, so the scores are not comparable to that index.
  • Math (AIME 2025) is the score on the AIME 2025 math contest, from 0 to 100. Artificial Analysis removed its old Math Index, and this contest score stands in for it. Only a few models have it.
  • Terminal-Bench v4.0 is the terminal task benchmark score, scaled from 0 to 100.
  • LiveBench Coding and Agentic Coding come from the official LiveBench release 2026_06_25, on a 0 to 100 scale. Coding averages code generation and completion. Agentic Coding averages the JavaScript, TypeScript and Python evaluations. Missing subtasks are skipped, and the details show how many were completed. Only reviewed model and effort matches appear.

Only models with a score for the picked benchmark appear. Whatever the benchmark, the cost axis uses the Intelligence Index task costs and the response time filter uses the Artificial Analysis response times.

Subscription plans

The Claude plan prices Anthropic models, and the Codex plan prices OpenAI models that are not open weights. With a plan picked, the page scales the API cost per task by the plan's monthly fee divided by the API value of its allowance. This assumes you use the whole allowance over a long window. It is a comparison estimate, not a provider invoice, and real limits and usage differ.

Max response time

Reasoning models can think for minutes before they answer. The slider hides variants whose median end-to-end response time is above the limit. That is the time from the request to the last token of a 500-token answer. Hidden variants stay on the chart as faint dots, and the Pareto line is computed again from the variants that remain. Variants with no measured response time are never hidden.
